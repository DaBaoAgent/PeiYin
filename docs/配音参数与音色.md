| 版本 | 参数要点 | 结论 |

| v1_基线_预设参数 | 旧预设（temp 0.7 / top_p 0.9 / top_k 15 / speed 0.95 / seed 20261020 / rep 1.35） | 作为对比基线 |

## 3. 误读修正表（speakFixes）

`D:\GPT-SoVITS\voices\dabao\preset.json` 的 `speakFixes` 维护「原文 → 正确读音」替换，新篇遇误读词直接追加。常见已收录类型：

- 古音/多音字：出降→出祥、投降→投祥、单于→蝉于、阏氏→胭脂、月氏→月支、龟兹→秋慈、吐蕃→土播、大宛→大渊、身毒→元毒
- 人名：荀彧→荀玉、张郃→张合、夏侯惇→夏侯蹲、沮授→举授、许褚→许楚
- 地名：并州→冰州、兖州→演州、邺城→夜城、犍为→前为、长坂坡→常坂坡、濡须→如须
- 数字/符号：〇→零、100→一百、3D→三低

# 出稿 + 配音工业化管线说明

> 本文是「徐艾伦 · 历史口播」项目的总管线文档：从选人物到配音归档，一条可复用的工业化流程。
> 关联文档：[口播稿规范](./口播稿规范.md)、[配音参数与音色](./配音参数与音色.md)、[对标爆款拆解报告](./对标爆款拆解报告.md)、[钩子方案库](./钩子方案库.md)。

---

## 1. 这条管线做什么

以「历史人物口播」为内容形态（动画 + 克隆配音，账号：**徐艾伦**），批量产出：

- **口播稿**：`出稿/0XX_人物名/口播稿.md`（约 2500~3500 字 / 10 分钟级）
- **克隆配音**：`出稿/0XX_人物名/配音.wav` + `配音.json`（dabao 音色，GPT-SoVITS v2 零样本克隆）

统一风格基线：

- 钩子开头（反常识提问 / 反差人设）
- 分节讲述 + 现代比喻（KPI、源代码、优化、上岸）
- 至少 1 句可截图传播的金句
- 结尾落到「这跟今天的你有什么关系」
- 结尾固定：**"我是艾伦，遛狗去了，白了个白。"**（"拜"读 bái）

## 2. 每篇生产流程（7 步）

```text
选人物 → 建目录 → 写口播稿 → 转纯文本 → 配音 → 听审 → 归档
```

1. **选人物**：挑「有反差」的——你以为他是 A，其实他是 B（参考 `对标爆款拆解报告.md` 的选题标准；避免与已有编号重复）。
2. **建目录**：`出稿/0XX_人物名/`，编号顺序递增，不跳号、不重排。
3. **写口播稿**：按 `口播稿规范.md` 的七步骨架写，存入 `口播稿.md`。
4. **转纯文本**：去掉标题 / 引号 / 括号，存为 `workdir/tts/XX_全篇.txt`（数字一律写中文，避免 TTS 读错）。
5. **配音**：跑 `dabao_tts.py`（命令见下），输出 `配音.wav` + `配音.json` + `narration-chunks/`。
6. **听审**：按 `AI味审核清单.md` 检查，有问题调参重配。
7. **归档**：完成后把整目录移入 `出稿/@已做/`。

## 3. 配音工具链

| 项 | 位置 / 值 |
|---|---|
| 主脚本 | `D:\GPT-SoVITS\dabao_tts.py` |
| 快捷入口 | `D:\GPT-SoVITS\dabao_tts.cmd` |
| 参数配置 | `D:\GPT-SoVITS\voices\dabao\preset.json` |
| 服务 | 本机 GPT-SoVITS api_v2（127.0.0.1:9880，GPU 推理，脚本自动拉起/复用） |
| 批量脚本 | `scripts/run_dabao_batch.ps1`（模板，改任务表即用） |

### 单篇配音（一键）

```powershell
D:\GPT-SoVITS\dabao_tts.cmd --text-file <全篇.txt> --out <出稿\0XX_人物名\配音.wav> --force
```

自动完成：切段（cut1，≤78 字）→ 逐段合成 → 句间静音压缩 → 噪声门 → 拼接 → 输出
`配音.wav` + 同名 `配音.json` + `narration-chunks\`。

常用参数：

| 参数 | 作用 |
|---|---|
| `--force` | 忽略缓存，强制重新合成 |
| `--keep-server` | 跑完不关服务（批量时省模型加载时间） |
| `--text` | 直接传文本 |

### 批量配音（多篇）

```powershell
cd D:\@kaifa\lishi
.\scripts\run_dabao_batch.ps1
```

1. 把每篇纯文本放进 `workdir/tts/`（`XX_全篇.txt`）；
2. 编辑脚本中的「任务表」`$jobs`，追加 `@{ n = '0XX_人物名'; txt = 'XX_全篇.txt' }`；
3. 运行脚本，日志写入 `workdir/logs/batch_<时间戳>.log`，每篇运行日志落 `出稿/0XX_人物名/run_stdout.log`。

## 4. 关键参数（2026-10-24 定稿 v3_流畅起伏）

| 项 | 值 |
|---|---|
| 音色 | dabao（徐艾伦克隆音，参考 `ref_dabao3-1.wav`） |
| 模型 | GPT-SoVITS v2 zero-shot |
| temperature / top_p / top_k | 0.8 / 0.9 / 20 |
| seed / repetition_penalty | -1 / 1.3 |
| speed_factor | 1.0 |
| 分句 | cut1，≤78 字/段；>6.2 字/秒判定截断，重配 ≤3 次 |
| 后处理 | 句间静音压至 100ms（>150ms 判定可压缩）、-40dB 静音门、-33dB 噪声门、段间补 20ms |

参数沿革：10/23 曾用旧参数（temp 0.7 / top_p 0.9 / top_k 15 / speed 0.95 / seed 20261020 / rep 1.35）跑过伏羲、女娲首版；10/24 音色审核后定为 v3（样音见 `reference/音色审核/`），刘秀已用 v3 重配（`配音_v3.wav`），006 女娲～011 商汤共 6 篇已按 v3 完成。

## 5. 已知事项

- **tts_infer.yaml 会被引擎重写**：GPT-SoVITS 服务每次启动会把 `GPT_SoVITS\configs\tts_infer.yaml` 重置为默认（device: cpu / is_half: false），但 api_v2 会自动探测 CUDA，推理仍走 GPU（RTX 4070 实测约 50-60 秒/段，FP32）。若需 FP16 提速，须在服务启动后再写入 `is_half: true`，或直接改引擎模板。
- **批量配音用 `--keep-server`** 复用已启动的服务，省掉每篇约 1 分钟的模型加载。
- **多音字/误读修正**：`preset.json` 的 `speakFixes` 字段维护了一份「原文 → 正确读音」替换表（如 出降→出祥、荀彧→荀玉），新篇遇误读词可在此追加。

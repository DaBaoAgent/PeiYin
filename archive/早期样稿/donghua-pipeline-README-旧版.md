# 徐艾伦 · 历史动画口播管线（donghua-pipeline）

> 用途：用动画 + 艾伦克隆配音，做短平快历史口播视频
> 账号：徐艾伦
> 结尾固定：**"我是艾伦，遛狗去了，拜了个拜。"**

## 每做一个新选题的标准流程

1. **选人物**：挑"有反差"的——你以为他是A，其实他是B（参考报告里的选题标准）
2. **挑钩子**：从 `02-钩子方案/` 选一组，或按公式现写
3. **写口播稿**：按 `01-报告/` 里的七段式（压缩成五段）写，时长3-5分钟，约1000-1400字
4. **标动画提示**：每段括号里写清楚这一段画面该出什么
5. **配配音提示**：语气、节奏、重音标出来
6. **克隆配音**：用艾伦本音录参考，或直接喂给TTS
7. **做动画**：按画面清单做关键帧

---

## 风格红线（别踩）

- ❌ 不要写子非秋月那种第一人称历史人物独白（那是上一个号的路线）
- ❌ 不要超过5分钟（动画制作成本高，短平快才能日更/周更）
- ❌ 不要用文学比喻（"像搁了很久的笔"这种），要用现代比喻（KPI、源代码、优化、上岸）
- ❌ 不要忘了结尾那句"我是艾伦，遛狗去了，拜了个拜"
- ✅ 每篇至少3个现代比喻
- ✅ 每篇至少1句能截图传播的金句
- ✅ 结尾一定要落到"这跟今天的你有什么关系"

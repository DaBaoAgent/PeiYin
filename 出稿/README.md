## 每篇固定结构

```
出稿/
└── 0XX_人物名/
    ├── 口播稿.md          ← 完整口播稿，结尾固定"我是艾伦，遛狗去了，白了个白"
    ├── 配音.wav           ← 全篇配音（dabao 音色，44.1kHz 单声道 PCM）
    ├── 配音.json          ← 分段时间戳与元数据（总时长/每段时间轴/参数）
    ├── run_stdout.log     ← 本篇 TTS 运行日志（可选保留）
    └── narration-chunks/  ← 分段音频（NNN-<hash>.wav + .tight.wav）
```

## 配音参数（统一，v3 定稿）

- 音色：dabao（`ref_dabao3-1.wav` 零样本克隆）
- temperature 0.8 / top_p 0.9 / top_k 20 / speed 1.0 / seed -1 / repetition_penalty 1.3
- 数字一律写中文（"三千"不是"3000"，"四十二万"不是"42万"），避免 TTS 读错
- 咬字优先：宁可稍慢，不吞字
- 完整参数与误读修正表见 `docs/配音参数与音色.md`
